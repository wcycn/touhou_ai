# 项目状态

版本：1.1.0  
日期：2026-07-29

## 已验证

- 用户已在真实游戏中验证截图、检测、规则决策和基本人物控制闭环。
- 当前推理后端是 Ultralytics/PyTorch，不依赖 MindSpore。
- X11窗口可自动发现、定位、激活，并在移动或缩放后刷新坐标。
- 无法确认游戏焦点时，正式控制不会发送动作。
- 安全观察模式从模块层禁用 PyAutoGUI 输入。
- 新统一 GUI 可启动并保持运行。
- 会话可记录为 JSONL、抽样图片和汇总元数据，并生成离线报告。
- 已实现自机跟踪、短时漏检预测和超时强制停控。
- 已实现敌弹跨帧匹配、速度估计、TTC与候选方向风险比较。
- 已实现边界保护、移动防抖和只发送状态差异的按键状态机。
- 已实现保守场景门控，未知或非战斗画面不允许移动射击。
- 已实现会话质量分析、人工审核候选导出和YOLO验证集评估入口。
- 发布版自动测试不启动游戏、不发送按键。
- 模型由项目作者使用自行整理和标注的数据训练；原始游戏截图数据不随仓库发布。
- 模型权重由 Hugging Face 托管，程序可自动下载并校验 SHA-256。

## 尚未证明

- 尚无标准化真实战斗验证集，模型准确率未知。
- 尚未建立稳定生存时间、Miss次数或通关率指标。
- 四方向规划已实现，但尚未用真实录像校准移动速度和风险权重。
- 尚无菜单、暂停、死亡、续关和结局画面数据，因此只能安全停控，不能自动导航。

## 发布边界

- 新版只包含一个 GUI：`desktop_gui.py`。
- 旧 GUI、远程部署脚本、在线大模型接口和历史配置未进入发布版。
- 游戏本体未进入发布版，必须由用户自行合法取得。
- 运行生成的 `sessions/` 与 `runs/` 默认被 Git 忽略。
- GitHub 仓库只发布代码；模型权重由 `wcycn/touhou-ai-yolo` 发布。
- 项目源代码与 Hugging Face 模型权重采用 GNU AGPL v3.0 发布。
- 游戏本体与原始训练截图不在项目许可证的授权范围内。

后续工程顺序和验收标准见 `ROADMAP.md`。
